## Open Digger: preserve the reported original-author permission

The selected [Digger documentation](https://github.com/sobomax/digger/blob/e85cab1164f0304b3e66f371a5997d83f7a0090a/digger.txt) and Andrew Jenner's [official FAQ](https://www.digger.org/faq.html) report that original author Rob Sleath retained rights to use the code for other products and granted rights in Digger Remastered, which Jenner licensed under GPL. This is explicit author-reported permission evidence; it must not be flattened into the “contributor badge only” finding for unrelated projects. The underlying agreement and its full scope have not been independently authenticated here.

The same account distinguishes Digger Remastered from distributing original Windmill game copies. Its historical legal assertions and its inference from a lack of objection are not adopted as current legal advice or a separate original-retail grant. The [selected modern README](https://github.com/sobomax/digger/blob/e85cab1164f0304b3e66f371a5997d83f7a0090a/README.md) describes mixed per-file Public Domain, Beer-Ware, BSD-2-Clause and GPL-2.0 contributions. The [game C](https://github.com/sobomax/digger/blob/e85cab1164f0304b3e66f371a5997d83f7a0090a/digger.c) retains Andrew Jenner attribution; [main.c](https://github.com/sobomax/digger/blob/e85cab1164f0304b3e66f371a5997d83f7a0090a/main.c) also retains Windmill attribution. It is not a wholly MIT or wholly public-domain distribution. This historical mixed/GPL route differs from the current new permissive-code intake.

Open Digger's eight authored levels and replacement presentation have separate CC0 records. This review changes no pack bytes or gameplay results and does not independently repeat the prior selected-object, audio-exclusion or complete-content audit. Byte-for-byte matching and clean-room isolation are not certified. Reopening under current intake requires an accepted code route and any needed permission/dependency scope evidence; it does not require pretending that the reported original-author permission is absent.

Open Junction's authored CC0 screens, rails, glyphs, scenario and null-audio build address separate content/platform questions. Prior deliveries and save tests are not original-code permission evidence. The public engine summary and limitation now disclose this gate. The existing release remains; it is not a cleared new permissive-code addition. ## Open Skyways: a rewritten engine, rather than a verified matching reconstruction

The selected [SkyRoads README](https://github.com/haroldo-ok/skyroads-32x/blob/df219e03b854153291b32224593013b60d861d40/README.md) describes disassembling the executable, recovering formats/algorithms and rewriting the engine as approximately 3,000 lines of portable C11. It states that original code does not execute and reports an attract-demo regression. These are upstream method/test claims, not independently reproduced matching or clean-room evidence. The category is now **Engine recreation**; a documented disassembly basis alone did not justify treating this rewrite as the fourth strict decompilation addition.

The [MIT notice](https://github.com/haroldo-ok/skyroads-32x/blob/df219e03b854153291b32224593013b60d861d40/LICENSE) credits the contributor rewrite, separately lists Nuked OPL3's LGPL exception, and excludes original SkyRoads game materials. It cites an original readme welcoming modification/reverse engineering. The original developer's history page and index returned HTTP 502 through this session's web reader, so no independent scope verification of that statement is claimed. No original binary/archive was fetched to pursue it. Permission to reverse engineer, a contributor rewrite license, permission for retail files, and a clean-room certificate are distinct evidence questions. This review makes no determination that the rewritten engine is infringing or that it necessarily requires a new retail-code grant.

Open Skyways' published null-audio WASM package and 30 authored roads are preserved. The Sega 32X artifact described elsewhere in the upstream tree is not the selected browser runtime; no 32X ROM was fetched or executed. Exact selected dependencies, retained code-origin scope and complete replacement-content provenance are not recertified by this metadata review. Broad recreation expansion remains paused. Completing the authored roads demonstrates that campaign's gameplay, without changing the source classification or filling a fifth decompilation slot.
