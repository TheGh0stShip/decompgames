## OpenPhantom

`OpenPhantom/OpenPhantom`, revision `1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431`, 55 stars at read. Classification at this pin: retail executable patch loader and modding tools, with a planned future engine. This is not a completed source-decompiled game or a native replacement game runtime. The [root README](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/README.md) distinguishes the current installer/legacy patches from the unstarted engine/editor. Their pinned READMEs contain only a future-work heading. Proton compatibility does not establish a native Linux engine or WebAssembly build.

The [legacy README](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/legacy/README.md) describes a 32-bit loader and feature DLLs that patch the original `WMAIN.EXE` in memory. [Legacy CMake](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/legacy/CMakeLists.txt) rejects non-32-bit configurations. Original executable and game content are required; independently replacing media would leave retail code execution. The [MIT notice](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/LICENSE), copyright 2026 OpenPhantom, covers this project's source, not the original executable/assets or all packaged third-party binaries.

The [installer notice](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/installer/THIRD-PARTY-NOTICES.md) separately identifies VLC GPL2, FFmpeg GPL3, DSOAL LGPL2.1 and bundled OpenAL Soft LGPL2, plus distinct crypto/wrapper notices. The [legacy notice](https://github.com/OpenPhantom/OpenPhantom/blob/1eb1ea70b618dc7991f4e9b8c878ecf1fd3dc431/legacy/dist/THIRD-PARTY-NOTICES.txt) also identifies MPL2 MemoryModule and distinguishes its archive from installer-supplied video components. These are selected upstream packaging records, not an independently audited exact-link or source-compliance certification. They cannot be replaced by the root MIT label.

Disposition: not an eligible standalone ROM/executable-free game. Reopen only when a real native source runtime exists, its full code/dependency scope is eligible, a complete independent content package is available and a browser build can be tested. No engineering of the placeholder engine under the paused broad engine-recreation priority, no retail executable acquired and no entry/count change.

## Ballanced

`doyaGu/Ballanced`, default `sdl` branch at `e501fee83e4206f24cd843716a9a6c1f31edcbf7`, 45 stars at read. Classification: decompilation-derived Player combined with source-level Virtools-compatible engine reimplementations. [Player's README](https://github.com/doyaGu/BallancePlayer/blob/e507329544c8d0000b8449371caca203b77b7225/README.md) describes its decompilation/improvement origin, while CK2 describes an engine reimplementation. This audit does not establish byte matching for the entire commercial game, complete reconstructed game content or clean-room methodology. Do not count this composite runtime as a new matching decompilation or an independent original replacement game.

The [root README](https://github.com/doyaGu/Ballanced/blob/e501fee83e4206f24cd843716a9a6c1f31edcbf7/README.md) requires original Ballance assets and compatible directory layout, including `base.cmo` and `Database.tdb`. These compositions/database and other game data require separate permission or complete independent replacement, along with graphics/models, animation, text/UI, audio and all scenario/map content. No full independent pack was established; a small authored rolling-ball scene would not establish a completed Ballance release.

Code notices are component-specific. The actual [root MIT](https://github.com/doyaGu/Ballanced/blob/e501fee83e4206f24cd843716a9a6c1f31edcbf7/LICENSE) and [Player MIT](https://github.com/doyaGu/BallancePlayer/blob/e507329544c8d0000b8449371caca203b77b7225/LICENSE) name kakuty, copyright 2022. Pinned CK2, VxMath, RenderEngine, BuildingBlocks, Plugins and ParameterOperations carry Apache-2.0 declarations. The pinned SdlInputManager and SdlSoundManager repositories have no LICENSE/COPYING/NOTICE paths in the reviewed trees, and their nine C++/header files contain no identified licence grant. No component-specific scope connecting the parent MIT grant to these separate repositories was established. Their grants, reconstructed engine provenance and remaining nested/transitive notices must be resolved before a whole-distribution permissive claim. Missing component notices are a scope gate, not an assertion that upstream lacks authority to offer one.

[Player CMake](https://github.com/doyaGu/BallancePlayer/blob/e507329544c8d0000b8449371caca203b77b7225/CMakeLists.txt) explicitly uses the assembled CK2/VxMath targets without an external Virtools SDK. Its optional standalone fallback can fetch a separately pinned legacy SDK; that path was not selected or fetched here and is not assumed to be required by the superproject. Review it separately if a future build selects it.

Browser gate: the [build guide](https://github.com/doyaGu/Ballanced/blob/e501fee83e4206f24cd843716a9a6c1f31edcbf7/BUILD.md) supports native Windows/Linux/macOS and both shared-module and static builds. Static modules are an available adaptation path, not browser proof. [RenderEngine CMake](https://github.com/doyaGu/CKRenderEngine/blob/8c4b40a43d359cf0f8f5495d07619c31ad29f76f/CMakeLists.txt) selects SDL_GPU and SDL3 3.4.8, with platform shader/backend paths. Exact selected SDL/toolchain versions, shader/media inputs, Web graphics and frame scheduling, filesystem/persistence and a working ROM-free browser build remain unverified. No conclusion that a port is impossible.

Disposition: recognizable native reconstructed runtime, blocked for current integration by component grant/closure uncertainty, complete independent game content and an unverified browser target. Preserve its classification below completed actual-game decompilation intake; no broad engine expansion or generic replacement fixture promoted.
