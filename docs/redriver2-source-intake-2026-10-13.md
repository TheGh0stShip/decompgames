# REDRIVER2 source intake — October 13

Reviewed `OpenDriver2/REDRIVER2` at `b2d8857426f815007486def9bd23f9a6007a2c64`, with 1,397 GitHub stars at read. No Driver 2/REDRIVER2 entry was found in the 83-entry catalog. This is a read-only source, build and notice audit: no game media or executable downloaded, no compile or browser test. [Snapshot hashes](redriver2-source-snapshot-2026-10-13.json) identify the reviewed text and distinguish the unpinned installation wiki from pinned repository files.

Classification: decompilation-derived native source port. The [pinned README](https://github.com/OpenDriver2/REDRIVER2/blob/b2d8857426f815007486def9bd23f9a6007a2c64/README.md) describes reconstruction from MIPS into C using symbols, Ghidra and manual work, except the Memory Card menu. The game runs native code with a platform compatibility layer. It is not whole-game CPU emulation; PsyCross does implement software GTE and GPU/VRAM/CD/SPU compatibility. Neither native execution nor a licence declaration establishes clean-room isolation.

Code gate: the [root MIT notice](https://github.com/OpenDriver2/REDRIVER2/blob/b2d8857426f815007486def9bd23f9a6007a2c64/LICENSE) names SoapyMan, copyright 2020. This is an actual permissive declaration, but the reviewed documents do not establish original rights-holder permission for the complete reconstructed retail game code. Code provenance and grant scope remain unresolved for this intake. This finding does not assert that upstream is unlawful.

Content gate: the [installation instructions](https://github.com/OpenDriver2/REDRIVER2/wiki/Installation-instructions) require both original Driver 2 CDs and say the project does not supply their contents. No complete independently licensed replacement set was established for graphics, models, animation, maps, scripts, text, audio and video. Authoring replacement textures alone would not meet ROM-free gameplay requirements. No retail media was obtained or included in a distribution.

Browser gate: the [pinned Premake target](https://github.com/OpenDriver2/REDRIVER2/blob/b2d8857426f815007486def9bd23f9a6007a2c64/src_rebuild/premake5.lua) selects Emscripten SDL2/libjpeg, ES2 compatibility, Asyncify and memory growth, and preloads both web-demo and data directories. Its older memory/settings syntax needs validation with a current toolchain. [WebLoadCDImage](https://github.com/OpenDriver2/REDRIVER2/blob/b2d8857426f815007486def9bd23f9a6007a2c64/src_rebuild/platform/Emscripten/emscripten_exports.cpp) passes disc bytes into PsyCross's memory CD filesystem. A local-storage filesystem wrapper exists, but these source paths are browser potential, not verified disc-free gameplay, persistence or rebuild evidence.

Dependency gate: the pinned PsyCross submodule is `e56e4cde1c2b8a15e0d4e38b26cdd9202e0d17e6`; its [MIT notice](https://github.com/OpenDriver2/PsyCross/blob/e56e4cde1c2b8a15e0d4e38b26cdd9202e0d17e6/LICENSE) names the REDRIVER2 Project, copyright 2020. Its README credits a TOMB5 framework base and describes Psy-Q-compatible APIs. Inherited framework/SDK source scope needs review separately from the root MIT notice. SDL2, OpenAL and the Emscripten libjpeg/runtime inputs need exact selected versions, notices and actual-link closure. An OpenAL link name alone does not establish which Web implementation is shipped. The included [Premake Emscripten extension](https://github.com/OpenDriver2/REDRIVER2/blob/b2d8857426f815007486def9bd23f9a6007a2c64/src_rebuild/premake_modules/emscripten/LICENSE.txt) carries BSD-3-Clause terms, separately from game/framework MIT. Other build extensions and transitive inputs have not received a complete release audit.

Disposition: a popular actual source-port lead with concrete Web support, but blocked for the current permissive ROM-free catalog. Reopen when reconstructed game/framework code permission and provenance, a complete independent content pack, selected dependency closure and a current browser build are established; then require muted gameplay, save and source-rebuild verification. A small authored driving fixture would not establish a completed Driver 2 release. No new entry, deployment, player or audio claim. Mario Party 2/3 and Halo remain untouched; private ROM research remains private.
