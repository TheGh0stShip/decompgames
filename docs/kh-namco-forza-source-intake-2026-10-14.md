# Kingdom Hearts, Namco 2x Systems and Forza intake

Catalog **90**; strict additional-decompilation milestone **4/5**. Three new projects were reviewed, covering twelve nonduplicate title names. None is ready for this permissive-code, independent-content, ROM-free browser intake. [Nineteen pinned text hashes, five scoped snapshots and decisions](kh-namco-forza-source-intake-2026-10-14.json). Audit time crossed midnight UTC; this document uses the October 14 America/Denver date.

## Kingdom Hearts 358/2 Days

[Yokimitsuro/khdays-port](https://github.com/Yokimitsuro/khdays-port/tree/43621fb4fd0ea9c907cc2aa7c6e4d0e0ce77cf97), pin `43621fb4fd0ea9c907cc2aa7c6e4d0e0ce77cf97`, had 64 stars and 187 tree files. It is an experimental native runtime developed beside a matching Nintendo DS decompilation. The README distinguishes working asset/front-end systems from its room-zero gameplay harness, which is expressly **not a reconstructed mission or combat loop**. Menu/character-select progress is not completed gameplay acceptance.

Its MIT grant covers original contributor work. The [exact decompilation submodule](https://github.com/Yokimitsuro/khdays-decomp/tree/d418c18302e538265b6a891580d77bb7f647d887) limits CC0 to contributor work and reserves the original game/assets to their owners. Its reported real-C coverage is approximately 75.3% of functions and 49.26% of code bytes, with ASM placeholders and SDK identifications separately counted. Those are upstream statistics, not matching checks performed here; a CC0 label does not clear original SDK/middleware or all reconstructed retail content.

Dependencies require their own treatment. [CMake](https://github.com/Yokimitsuro/khdays-port/blob/43621fb4fd0ea9c907cc2aa7c6e4d0e0ce77cf97/CMakeLists.txt) pins the SDL3 3.4.12 archive by SHA-256, but default PNG/glTF features fetch stb and cgltf from moving `master` branches. Default UI also selects ImGui v1.91.6, which is absent from the inspected [component notice list](https://github.com/Yokimitsuro/khdays-port/blob/43621fb4fd0ea9c907cc2aa7c6e4d0e0ce77cf97/THIRD_PARTY_NOTICES.md). That is a selected-notice/pinning gap, not a claim that ImGui has no upstream license. Apicula and Vulkan shaderc are documented reference/build tools, not automatically linked runtime dependencies. The renderer uses SDL3 GPU with generated SPIR-V; browser backend compatibility remains unverified.

**Blockers:** no complete reconstructed mission/combat loop, original ROM/NitroFS media and scripts, no full independent models/skeletons/animation/maps/text/audio package, inherited-code/SDK provenance and exact dependency closure, and verified Web adaptation. Mod overrides do not constitute a complete independent replacement campaign.

## Namco 2x Systems

[spacestate1/namco22-decompile](https://github.com/spacestate1/namco22-decompile/tree/a9dab183eb29e941629b473e4172b16835576d94), pin `a9dab183eb29e941629b473e4172b16835576d94`, had 187 stars and 605 tree files. Reviewed title names: Prop Cycle, Rave Racer, Tokyo Wars, Dirt Dash, Armadillo Racing, Time Crisis, Ace Driver, Cyber Commando, Cyber Sled and Time Crisis II. None duplicates the current catalog.

Despite the repository name, its [per-game methodology](https://github.com/spacestate1/namco22-decompile/blob/a9dab183eb29e941629b473e4172b16835576d94/README.md#how-it-was-made) is mixed. Prop Cycle uses hand-corrected Ghidra-derived C. Most other listed main programs are translated to C by project tools with varying manual rewriting; DSP, controller and sound programs are generated from supplied ROMs during build. Classify those paths as static translation/recompilation with hardware interfaces, rather than counting ten finished source decompilations. Upstream MAME-comparison and playthrough claims were not reproduced here.

The [license section](https://github.com/spacestate1/namco22-decompile/blob/a9dab183eb29e941629b473e4172b16835576d94/README.md#license) explicitly limits MIT to the project's own work and excludes Namco-derived generated programs in `*/gen/` and original game files. Thus even replacing external graphics/audio would not establish permission for the translated game programs. Original game ROMs and applicable DSP/sound/controller images remain build and runtime requirements.

The inspected native recipes select SDL2, OpenGL, zlib and shared engine components; the README separately identifies Nuklear and Windows Mesa terms. Exact selected dependency versions/notices and transitive closure are unverified. **Blockers:** explicitly excluded original translated code, build-time and runtime ROM requirements, no complete independently authored program/content replacement, and no verified browser gameplay. These are intake exclusions, not a judgment about upstream interoperability work.

## Forza Horizon 1: ReImagined

[Dyotson/ForzaHorizon1-ReImagined](https://github.com/Dyotson/ForzaHorizon1-ReImagined/tree/e635fa8e3f33873acca33e609013bb9b57077925), pin `e635fa8e3f33873acca33e609013bb9b57077925`, had 118 stars and 254 tree files. Its own documentation says the original Xbox 360 PowerPC executable is **statically recompiled to C++** using ReXGlue. Classify this as static recompilation plus a native platform/HLE runtime, not source decompilation. Future browser compatibility would not change that milestone classification.

The root MIT declaration names Dyotson and contributors. Generated Microsoft game code comes from the user's original executable; no separate grant for that translated code or complete game content was established by this review. The inspected [CMake](https://github.com/Dyotson/ForzaHorizon1-ReImagined/blob/e635fa8e3f33873acca33e609013bb9b57077925/forza-recomp/CMakeLists.txt) performs code generation on first configuration. Its skip-codegen option requires already-generated sources; it does not remove the original-code dependency.

The [SDK patch script](https://github.com/Dyotson/ForzaHorizon1-ReImagined/blob/e635fa8e3f33873acca33e609013bb9b57077925/tools/build_rexglue_sdk.sh) pins ReXGlue `bd833a2ab69d305f99ddf57418fc38ffec8af93d`. That SDK's [BSD-3-Clause notice](https://github.com/rexglue/rexglue-sdk/blob/bd833a2ab69d305f99ddf57418fc38ffec8af93d/LICENSE) names Tom Clay and retains Xenia attribution, separately from project MIT. Full patched GPU/runtime/transitive closure was not audited. Native Vulkan, OS/fiber/thread interfaces and separately licensed Windows CRT/SDK tooling cannot be assumed to share MIT or an established browser backend.

**Blockers:** original executable/game-data dependence and unestablished translated-code permission, no independent full vehicle/world/animation/audio/text/script package, exact runtime/dependency closure and verified browser adaptation. No generated game code, retail files, SDK binaries or installer was acquired, and no SDK script was executed. Halo-related repositories were not modified or audited.

## Verification limits

All **19 raw text files / 140,837 bytes** passed local hash checks. Deduplication covered the twelve listed title names against all 90 catalog entries. An initial Namco tree request ended early; its incomplete body was discarded and a complete, non-truncated tree was retrieved before review. No build, player, audible test, integration, runtime upload or deployment occurred; no clean-room isolation was certified. [Signal Survey](signal-survey-release.json) remains the latest release. Backlog/test-log checkpoints are byte-appended; unrelated local history is not staged. Mario Party 2/3, Halo and private prior ROM research remain untouched.
