# Recoil, Glover, FUEL and Freedom Fighters source intake

Four uncataloged titles reviewed on October 14, 2026. No eligible addition: catalog **88**, additional-decompilation milestone **4/5**. This is a source-only review, with no original game binaries, discs, ROMs, media, SDK/compiler binary packages or players downloaded or executed. Selected source/header excerpts were retained privately. Claude-owned games and private ROM research remain untouched.

The accompanying [snapshot](recoil-glover-fuel-freedom-source-snapshot-2026-10-14.json) records 24 exact raw UTF-8 text hashes, four untruncated repository-tree inventories and one optional dependency notice. Current pins were obtained directly from GitHub; searches only discovered candidates. Repository popularity describes the reconstruction projects, not the popularity of the original games. None has a verified browser game here.

## Recoil: declared MIT reconstruction, unfinished native runtime

[Vorta/RecoilRebuild](https://github.com/Vorta/RecoilRebuild/tree/1ca9763422e3d5c4bec7cd192b9156b8443037cc), pin `1ca9763422e3d5c4bec7cd192b9156b8443037cc`, four stars. [LICENSE](https://github.com/Vorta/RecoilRebuild/blob/1ca9763422e3d5c4bec7cd192b9156b8443037cc/LICENSE) declares MIT, copyright 2026 contributors. [README](https://github.com/Vorta/RecoilRebuild/blob/1ca9763422e3d5c4bec7cd192b9156b8443037cc/README.md) expressly separates that declaration from rights to the original game and third-party materials. Permission covering inherited game expression remains unresolved; no original-rightsholder grant or documented clean-room isolation was established by these texts.

Classify as an ongoing decompilation-derived native C/C++ reconstruction, not a completed source port, independent engine recreation or matching-result certificate. The [status document](https://github.com/Vorta/RecoilRebuild/blob/1ca9763422e3d5c4bec7cd192b9156b8443037cc/docs/reconstruction-status.md) distinguishes source recovery, function matching and final-image proof. Its dated native compile/link snapshot excludes gameplay and final-image acceptance; it explicitly does not claim end-to-end playability. We did not reproduce its build or matches.

The checkout is not a standalone build package: Visual C++ 5 SP3, legacy SDKs and external references/dependencies remain required. [WinMain](https://github.com/Vorta/RecoilRebuild/blob/1ca9763422e3d5c4bec7cd192b9156b8443037cc/src/WinMain.cpp) calls MFC's `AfxWinMain`; reviewed FMV code uses Windows MCI APIs and recovered data literals. These require selection-specific code/data attribution, SDK/runtime grants and functional browser adaptation. No complete independently authored graphics, animation, UI/text, missions/maps or audio pack exists in the reviewed evidence. **Blocked by unresolved inherited-code scope, unfinished standalone runtime, independent full content, dependency closure and unverified browser scheduling/rendering/input/storage.**

## Glover: incomplete ROM reconstruction with no identified overall grant

[rainchus/glover](https://github.com/rainchus/glover/tree/f2d2b2824e29a5d9b00718a283a3cb243be3ca52), pin `f2d2b2824e29a5d9b00718a283a3cb243be3ca52`, twelve stars. The untruncated tree has no identified LICENSE/COPYING/NOTICE/README grant. This is a scoped finding about this revision, not proof that permission cannot exist elsewhere.

[Makefile](https://github.com/rainchus/glover/blob/f2d2b2824e29a5d9b00718a283a3cb243be3ca52/Makefile) fails immediately without `baserom.us.z64`; it splits the ROM, compiles MIPS sources with bundled old GCC tooling, includes generated assembly/binary objects, links a ROM and compares against the base. Its `test` target invokes Mupen64Plus. [glover.yaml](https://github.com/rainchus/glover/blob/f2d2b2824e29a5d9b00718a283a3cb243be3ca52/glover.yaml) selects N64, ROM boot/entry/code/data segments and extracted assembly. The only `src/` C translation unit in this tree, `D920.c`, includes nonmatching assembly and PI hardware polling. This is an incomplete matching-decompilation scaffold; executing the rebuilt ROM in an emulator would still be emulation, not a native browser source port.

The separate [SDK header](https://github.com/rainchus/glover/blob/f2d2b2824e29a5d9b00718a283a3cb243be3ca52/include/PR/os.h) contains Silicon Graphics' proprietary/restricted notice. No game grant can be inferred from public availability, and this dependency notice is not permissive. Compiler binaries visible in the tree were not downloaded or executed. **Blocked by missing identified game-code grant, restrictive SDK scope, extensive extracted assembly/data dependence, no complete independent content and no verified portable browser runtime.**

## FUEL: partial source plus retail-derived object, no overall grant

[widberg/FUELDecompilation](https://github.com/widberg/FUELDecompilation/tree/bd6b69976602b2758ab8559a1557fde24861f193), pin `bd6b69976602b2758ab8559a1557fde24861f193`, twenty-seven stars. No identified overall grant in the untruncated tree. [README](https://github.com/widberg/FUELDecompilation/blob/bd6b69976602b2758ab8559a1557fde24861f193/README.md) identifies the proprietary Zouna engine, an original installation requirement and patched MSVC 8 plus DirectX SDK August 2008 prerequisites. It describes decompilation; that is not a permission grant or complete native-source reconstruction proof.

[CMake](https://github.com/widberg/FUELDecompilation/blob/bd6b69976602b2758ab8559a1557fde24861f193/CMakeLists.txt) combines compiled reconstructed sources with `libs/libfuel.obj`, stripping selected symbols using `coffdrop` and importing the resulting static library. The README attributes that object to a delinking technique. The retail-derived object was not downloaded; replacing external artwork alone would leave this code/data dependence. This is a partial decompilation and native reconstruction using original object material, not a standalone ROM/executable-free browser game.

Native build checks require compiler-specific user-call extensions; Windows linking selects Bink, XLive, AVI and DirectX libraries, with Direct3D renderer, Windows input/threads and save paths. Actual dependency grants, standalone replacements and browser adapters remain unresolved. Optional dmalloc has its own permissive Gray Watson notice. Optional mimalloc gitlink `a479aaba94a9b7b1d64f5199ae018d564b34700a` has separate Microsoft MIT terms; neither clears FUEL or the default `msvcrt` selection. No full transitive closure is claimed. **Blocked by unidentified overall game grant, original object/install/content requirements, Windows/proprietary dependency scope and no verified browser build.**

## Freedom Fighters: CC0-labelled matching scaffold, no game sources yet

[andresj-sanchez/frfi-decomp](https://github.com/andresj-sanchez/frfi-decomp/tree/4becacf5aa16da622cbd756c70a36f2717982ff4), pin `4becacf5aa16da622cbd756c70a36f2717982ff4`, two stars. Root LICENSE is CC0; it does not establish original-rightsholder permission for subsequently reconstructed game or SDK code. [README](https://github.com/andresj-sanchez/frfi-decomp/blob/4becacf5aa16da622cbd756c70a36f2717982ff4/README.md) describes a work-in-progress GameCube decompilation and requires a disc image. The untruncated tree contains no `src/` or `include/` game-source files.

[configure.py](https://github.com/andresj-sanchez/frfi-decomp/blob/4becacf5aa16da622cbd756c70a36f2717982ff4/configure.py) targets Gekko/PowerPC and ProDG 3.9.3, lists only two nonmatching runtime objects, and uses pinned matching-build tools. [Configuration](https://github.com/andresj-sanchez/frfi-decomp/blob/4becacf5aa16da622cbd756c70a36f2717982ff4/config/GFDE69/config.yml) points to the original `sys/main.dol`; [getting-started text](https://github.com/andresj-sanchez/frfi-decomp/blob/4becacf5aa16da622cbd756c70a36f2717982ff4/docs/getting_started.md) remains template-oriented. Tool downloads and matching analysis do not establish a portable finished game. **Blocked by absent reconstructed gameplay source, unresolved game/SDK provenance, original disc/data requirements, separate toolchain/dependency review, full independent content and no browser target.**

No player was started; gameplay, saves, sound and clean-room isolation are unverified. No new catalog entry, distribution upload or website deployment is justified by these findings. Revisit only when the named gates change; none is counted toward the fifth qualifying decompilation.
