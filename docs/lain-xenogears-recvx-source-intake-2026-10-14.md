# Lain, Xenogears and Code Veronica X source intake

Catalog **90**, strict additional-decompilation milestone **4/5**. All three titles are nonduplicates. Their MIT declarations make them relevant source leads, but none clears complete independently authored content, selected dependencies and ROM-free browser gameplay. These are source-intake blockers, not legal conclusions about upstream projects. [Pinned source hashes, gitlinks and decisions](lain-xenogears-recvx-source-intake-2026-10-14.json).

## Serial Experiments Lain

[Y0oshi/lain-psx-decompiled](https://github.com/Y0oshi/lain-psx-decompiled/tree/205c1977e2aa8d26128fcdbab19170c2c2bbde0e), pin `205c1977e2aa8d26128fcdbab19170c2c2bbde0e`, had 120 stars and 395 tree files. Upstream reports 321 matching game functions and a native C client using a PsyCross-derived SDK replacement. Matching and full-game/endings claims were not reproduced here. This is a decompilation-derived native port, not a generic console emulator or an independently verified clean-room implementation.

The [MIT notice](https://github.com/Y0oshi/lain-psx-decompiled/blob/205c1977e2aa8d26128fcdbab19170c2c2bbde0e/LICENSE) names Y0oshi. It is a repository declaration, not separately verified permission from the original game rights holders for every reconstructed unit or table. [Third-party documentation](https://github.com/Y0oshi/lain-psx-decompiled/blob/205c1977e2aa8d26128fcdbab19170c2c2bbde0e/thirdparty/README.md) distinguishes component terms: the inspected PsyCross notice is MIT and SDL2 notice is zlib; OpenAL Soft is LGPL-2.1-or-later and the release recipe links it statically. Do not flatten those terms into root MIT or certify relinking compliance from the README alone. Other listed components and selected/transitive closure remain unverified.

The [actual loader](https://github.com/Y0oshi/lain-psx-decompiled/blob/205c1977e2aa8d26128fcdbab19170c2c2bbde0e/port/client/psx_mem.c) opens a disc image, finds `SLPS_016.03` or `SLPS_016.04`, validates the PS-X header and copies the retail image's text, read-only data and data into a memory arena. This bootstrap dependence goes beyond external pictures and sound. It does not demonstrate execution of original machine instructions: gameplay is documented as compiled C, while original executable bytes provide the arena layout/data. Both discs still supply movies, voices, images, text and tables. The README also identifies a memory-card-derived icon, which is not independent replacement art.

The native [CMake](https://github.com/Y0oshi/lain-psx-decompiled/blob/205c1977e2aa8d26128fcdbab19170c2c2bbde0e/port/CMakeLists.txt) uses OpenGL, SDL2, OpenAL, a generated assembly arena and native file-dialog/mod tooling. No verified Emscripten game target was established. Mods and subtitle/dub packs do not constitute a complete independent narrative, media and bootstrap-data package. **Blocked:** inherited-code/table provenance, original executable/discs, independent full content, selected dependency terms and portable browser adaptation.

## Xenogears — Noah

[yaz0r/Noah](https://github.com/yaz0r/Noah/tree/d725fe231e56a895c17df0554042b9e2bd1acb78), pin `d725fe231e56a895c17df0554042b9e2bd1acb78`, had 77 stars and 291 tree files. Its README explicitly describes a **nonmatching** decompilation/reimplementation in modern C++, with PSX sound-chip emulation. Preserve that distinction; do not label it a byte-matching rebuild or a general console emulator. The MIT notice names Noah authors, with inherited game/content provenance still requiring separate review.

Upstream documents missing VM opcodes, collision problems, incomplete battles and world-map features that prevent normal progression. Its [ISO manager](https://github.com/yaz0r/Noah/blob/d725fe231e56a895c17df0554042b9e2bd1acb78/NoahLib/kernel/isoManager.cpp) opens `iso/1.bin`; the README asks for both original disc images. No complete independently authored field, battle, world-map, text, animation or sound campaign was established.

The [native target](https://github.com/yaz0r/Noah/blob/d725fe231e56a895c17df0554042b9e2bd1acb78/Noah/CMakeLists.txt) links NoahLib, bgfx, SDL3-static and SoLoud. Exact gitlinks are recorded; they do not alone establish component/transitive licensing. The included [SPU implementation](https://github.com/yaz0r/Noah/blob/d725fe231e56a895c17df0554042b9e2bd1acb78/NoahLib/kernel/audio/spuEmu/spu.cpp) has a BSD-3-Clause tag and names pSXAuthor and R. Belmont, separately from root MIT; full notice closure remains unverified. The library recipe also embeds `battleCursor.bin` through bin2c and generates shaders. Only the cursor's tree metadata was inspected, not its media bytes or provenance. No Emscripten gameplay was established merely from using portable dependencies. **Blocked:** incomplete normal progression, original discs, independent full content and embedded-data provenance, reconstructed-code/dependency closure and browser adaptation.

## Resident Evil: Code Veronica X — recvx-decomp

[AshfordFamily/recvx-decomp](https://github.com/AshfordFamily/recvx-decomp/tree/b1516946d388a5285149d8bdb618543e767f3c7c), pin `b1516946d388a5285149d8bdb618543e767f3c7c`, had 273 stars and 525 tree files. Upstream reports completed game/GFX/enemy reconstruction from PS2 MIPS to C. The documented test route repackages an original disc with the reconstructed ELF and runs it in PCSX2 or on a console. This is a matching-decompilation project with a console executable/ISO build, not an established native browser runtime. Completion was not independently measured here.

The MIT notice names AshfordFamily (2024–2026). The README recommends contacting Capcom for a publishing deal; that recommendation is not a separate original-rightsholder grant. [compile_config.json](https://github.com/AshfordFamily/recvx-decomp/blob/b1516946d388a5285149d8bdb618543e767f3c7c/compile_config.json) selects Metrowerks PS2 tools, Sony EE SDK headers/runtime libraries and CRI source/header paths. The README requires supplied Sony SDK 2.0.0 or 3.0.3 files. CRI, Katana and Metrowerks gitlinks were inventoried without downloading their SDK/compiler payloads; root MIT does not clear them.

Building requires the original `SLUS_201.84`; playtesting additionally requires the original disc's complete content. No independent models, textures, animation, audio, maps, scripts or dialogue package, portable renderer/input/scheduler, or selection-specific browser dependency audit was established. **Blocked:** reconstructed-game and compiled SDK/CRI permission, original executable/disc content, independent complete campaign and native browser engineering. A completed PS2 decompilation is valuable progress but is not our ROM-free gameplay acceptance.

## Retained evidence and limits

Thirty raw text files totaling 270,483 bytes were hash-checked; title/alias deduplication passed against all 90 catalog entries. No retail media, executable, compiler, SDK payload or release bundle was fetched. No build, player, audible test, integration, runtime upload or deployment occurred. [Signal Survey](signal-survey-release.json) remains the latest released intake. The backlog/test log receive byte-appended checkpoints, with unrelated local history excluded from staging. Mario Party 2/3, Halo and private prior ROM research remain untouched.
