# Paper Rooms release — October 14, 2026 UTC

Paper Rooms is an original five-room flight challenge running the developer-released Glider 4 code translated to JavaScript by kodogo. It is a source port with independently authored replacement content, not a decompilation, emulation, the original campaign or a clean-room certification. The [distribution and gameplay record](paper-rooms-release.json) identifies selected source inputs, grants, hashes and observations.

Eight standalone flight/collision/collection/room-transition scripts are selected from kodogo/Glider at 9d5ff29905531e2d3c238a4c988f29d4f4ab1802; the original developer source is softdorothy/Glider4 at d023891da740a41d192e25d0e748fd1c54d940b8. Their MIT notice is retained. Only the soundOn default changes in selected upstream source. New host, utility, renderer and build code is MIT; independently authored room layouts, geometric graphic/animation design and text are CC0-1.0. The official CC0 legal text and separate dedication are packaged. Browser system fonts retain their own terms; no font file is shipped.

The package omits original houses, converted house data, raster sprites/masks, recordings, the original loader/HTML/CSS and Macintosh libraries/resources. The selected browser code uses DOM and Canvas APIs without a shipped third-party game library, native binary or proprietary SDK. Source ownership is supported by the developer's published source grant and the pinned translation grant, rather than inferred from a decompilation's root licence. Historical clean-room isolation is not certified. See the [earlier scoped source intake](liero-dink-glider-source-intake-2026-10-14.md) for why the original-media distribution was not selected.
