## Undertale: conditional source permission and a restrictive licence

`kittibyte/UndertaleDecomp`, `249ffa27ee7e7eee0d7ce84b736c294458b38685`, 126 stars, describes reconstruction of the Xbox v1.13X game in GameMaker/GML. This is a reported decompilation, not an official released-source port or an independently authored replacement game. Its main and vanilla branches represent the same game identity; matching completeness was not tested.

The [README](https://github.com/kittibyte/UndertaleDecomp/blob/249ffa27ee7e7eee0d7ce84b736c294458b38685/README.md) reports correspondence permitting a public repository with original game-specific assets removed and owners supplying their own data. That is relevant evidence of conditional permission to publish asset-free source. It is a maintainer-reported account, not a separately verified rights-holder grant to relicense, commercially use or redistribute complete compiled games. Contact details and the correspondence image are not reproduced here.

The actual [root licence](https://github.com/kittibyte/UndertaleDecomp/blob/249ffa27ee7e7eee0d7ce84b736c294458b38685/LICENSE) expressly limits use to noncommercial purposes, requires ownership of the game for compilation/use, and prohibits distributing compiled versions. It also distinguishes contributor-created work from Undertale rights. This is a custom restrictive licence, not MIT, CC0 or another accepted permissive whole-game grant. Independent replacement graphics alone would not remove the compiled-distribution restriction. Reopen only if applicable rights holders supply a grant that permits the intended modified browser distribution and covers the relevant reconstructed code.

The [setup contract](https://github.com/kittibyte/UndertaleDecomp/blob/249ffa27ee7e7eee0d7ce84b736c294458b38685/setup.sh) loads an original `data.win` through UndertaleModTool 0.8.2.0 and an asset importer. The three external-assets README files merely provide directories for extra fonts, sounds and sprites; they are not a complete independently authored content pack or provenance manifest. Full replacement graphics, animations, sounds/music, fonts, maps, dialogue/story and interface content would need separate review and authorship. None of the original media or expressive world/dialogue files was acquired for this audit.

The importer tool tag resolves to `UnderminersTeam/UndertaleModTool` at `473b731a8d16b75ac889972466470dc05d9c90ed`; its [licence text](https://github.com/UnderminersTeam/UndertaleModTool/blob/473b731a8d16b75ac889972466470dc05d9c90ed/LICENSE.txt) is GPLv3. This is an external extraction/build-time tool, not proof of a GPL game runtime or cleared imported assets. Its Underanalyzer gitlink and other tool dependencies remain separately governed and were not executed or fully audited.

There is an actual [HTML5 options file](https://github.com/kittibyte/UndertaleDecomp/blob/249ffa27ee7e7eee0d7ce84b736c294458b38685/options/html5/options_html5.yy), specifying WebGL and an HTML output name. This is more specific than merely using GameMaker, but does not demonstrate successful HTML5 gameplay, WebAssembly output, source-port completeness, save/stop behavior or silent startup. The documented build uses GameMaker Studio 2 beta; the applicable compiler/export runner terms and selected runtime dependencies have not been closed. No GameMaker installation or export was attempted while the compiled-distribution gate remains explicit.

## Strikers: matching reconstruction and a native port of the same game

`yannicksuter/smstrikers-decomp`, `d1f357ffeb1d8e89311edebf9a4b304b05ece7bb`, 101 stars, documents a matching GameCube reconstruction. Its [README](https://github.com/yannicksuter/smstrikers-decomp/blob/d1f357ffeb1d8e89311edebf9a4b304b05ece7bb/README.md) reports complete code/linking for three retail regions, requiring original input and comparing resulting DOL hashes. This audit did not reproduce those matching results. The upstream target is a retail-compatible console executable; it is not itself a modern browser port.

`YlPorts/strikers-android`, `bf27d6da7821479a17c1cc888473e743e3e985c1`, three stars, contains a decompilation-derived native port. Its [README](https://github.com/YlPorts/strikers-android/blob/bf27d6da7821479a17c1cc888473e743e3e985c1/README.md) describes Windows, Linux and macOS gameplay using original data, with Android adaptations visible in its dependency configuration. Upstream, port and regional editions count as one game lead. Neither repository is in the existing 87-entry catalog.

The upstream [rights notice](https://github.com/yannicksuter/smstrikers-decomp/blob/d1f357ffeb1d8e89311edebf9a4b304b05ece7bb/LICENSE) limits CC0 to original contributions whose rights contributors control, excludes third-party game-derived expression, and grants no blanket permission for retail-equivalent outputs. The port README repeats that scope and identifies its policy as source-only. These explicit limits prevent treating a CC0 badge as permissive permission for the full reconstructed game. This code gate remains even if every original model, texture or sound is replaced. No clean-room isolation is certified.

Dependencies are also mixed. The port's vendored Aurora has an MIT notice; the exact upstream MusyX gitlink `98ecfd21b3cdb550e5f22a90696591fede1c3cc6` has an [MIT notice](https://github.com/yannicksuter/musyx/blob/98ecfd21b3cdb550e5f22a90696591fede1c3cc6/LICENSE), also retained in the port. The port expressly notes that this does not establish the licensors' rights in all reconstructed middleware. Its vendored copy may have port changes; it was not assumed byte-identical to the upstream gitlink.

Historical ODE portions carry the BSD alternative, separately from game-specific additions. The upstream [ODE provenance record](https://github.com/yannicksuter/smstrikers-decomp/blob/d1f357ffeb1d8e89311edebf9a4b304b05ece7bb/docs/ode-provenance.md) records comparisons and an unresolved nested OPCODE origin. Those maintainer comparisons were read, not independently reproduced here. Two selected mathematical source headers separately preserve Sun permission notices and GPLv2-or-later eCos terms with a linking exception that retains source-availability requirements. They are not uniformly CC0. The Dolphin SDK gitlink `eb1234c45e6df75757c652c835507ca89674f9a8` describes SDK-library reconstruction and original archive inputs; no overall SDK licence was identified in its tree/README. The upstream [third-party inventory](https://github.com/yannicksuter/smstrikers-decomp/blob/d1f357ffeb1d8e89311edebf9a4b304b05ece7bb/THIRD_PARTY_NOTICES.md) also distinguishes Apache build tooling and proprietary runtime/SDK-derived material. This is selected evidence, not a complete linked-file clearance.

The port's [CMake](https://github.com/YlPorts/strikers-android/blob/bf27d6da7821479a17c1cc888473e743e3e985c1/smstrikers-port/CMakeLists.txt) defaults to Aurora, uses native SDL3/Dawn and requires a Clang toolchain; Aurora uses C++20. Dawn's WebGPU abstraction does not establish browser delivery. Selected configuration includes native compiler/linker handling, system/vendor/prebuilt dependency providers, save/card and filesystem paths. No verified Emscripten game build or browser scheduler/save/cleanup implementation was identified in the selected texts.

FFmpeg decoding defaults on but can be disabled. The dedicated [builder](https://github.com/YlPorts/strikers-android/blob/bf27d6da7821479a17c1cc888473e743e3e985c1/smstrikers-port/tools/build-ffmpeg.sh) specifies a static THP-only decoder, disables autodetection/network/other listed libraries and does not request GPL/nonfree enable flags. CMake can alternatively use system or externally supplied FFmpeg. No actual binary configuration was produced, so its exact terms cannot be inferred from the copied LGPL/GPL files alone. Selected Dawn, SDL3, UI, compression, font and other dependency source/notices would need an exact distribution inventory.

The README's asset-free claim is not sufficient on its own: CMake explicitly identifies the Windows executable icon as derived from the game's memory-card icon and compiles `assets/icon/strikers.rc`, which selects tracked `strikers.ico`. Tree metadata also lists TPL, PNG, ICO and ICNS assets. Only resource-script text and tree metadata were read; no image/icon payload was downloaded or certified. The native game otherwise requires original disc/extracted data. A ROM-free edition would need a complete independently authored and documented model/animation, stadium/world, interface/font/text and audio package, including replacing these compiled icon inputs.

Reopen Strikers after acceptable reconstructed-game and selected runtime/middleware grants are established, the full independent content pack exists, and an audited browser build passes gameplay, persistence and stop tests with sound off. Native startup, reported native gameplay, matching console hashes or a WebGPU label would not satisfy that release gate.
