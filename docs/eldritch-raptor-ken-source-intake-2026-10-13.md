## Eldritch: developer grant, missing content and browser work

`MinorKeyGames/Eldritch`, `a6554a05c55920d32ed2f6c5d3f9770e8e2cf517`, 105 stars at read, is the legacy 2014 release. Its [license](https://github.com/MinorKeyGames/Eldritch/blob/a6554a05c55920d32ed2f6c5d3f9770e8e2cf517/license.txt) is a direct Minor Key Games zlib grant with separately licensed libraries. Its [readme](https://github.com/MinorKeyGames/Eldritch/blob/a6554a05c55920d32ed2f6c5d3f9770e8e2cf517/readme.txt) requires FMOD Ex, which was excluded from redistribution. This legacy checkout is not the preferred audio-dependency route.

The developer's [official source page](https://eldritchgame.com/about.html) links the **2019-04-16** release and its [license](https://eldritchgame.com/bin/license.txt) and [readme](https://eldritchgame.com/bin/readme.txt). The [developer's announcement](https://minorkeygames.itch.io/eldritch/devlog/76853/2019-source-code-release) confirms that this release replaces FMOD with a modified SoLoud engine. These are original developer publications, providing stronger code-grant evidence than a reconstruction contributor's root license. They do not make Eldritch a decompilation or certify clean-room work.

The official ZIP is 7,625,114 bytes with 2,339 entries in the inspected central directory. Only selected textual members were fetched; their names, decompressed lengths and CRC32 values were checked against that directory, and SHA-256 values recorded. The full archive was not downloaded or hashed. The mutable download URL and HTTP metadata are not a Git revision; a future release must pin the complete selected source distribution. The prebuilt executables and library binaries were not fetched.

The 2019 license applies to supplied game source and identifies separately licensed zlib, SDL2, TinyXML, GLEW and SoLoud. The selected TinyXML and SDL notices are zlib-style; SoLoud's selected headers/core/backends retain its zlib-style notice. Its selected `stb_vorbis.c` supplies MIT/public-domain alternatives. The root notice reproduces zlib, GLEW and SoLoud terms. This is selected evidence, not certification of every decoder, platform backend, header, emitted JavaScript component or exact future link input. Those must be checked against the browser build's actual closure.

`versions.h` sets `BUILD_STEAM` to zero; the selected achievement implementation has redacted Steam branches. The Code::Blocks project nevertheless retains references to `libsteam_api.so` and absent Steam headers. These are stale project references to remove in a new build recipe, not evidence that the redacted 2019 source requires a proprietary Steam runtime. No Steam SDK was imported.

The source selects SDL through desktop platform macros; it has no explicit browser branch. `Framework3D::Main` runs a blocking `while (Tick())` loop. The GL2 renderer creates an SDL GL context, initializes desktop GLEW, uses BGRA as a vertex-attribute size and makes desktop framebuffer/default draw-buffer calls. A browser port needs explicit Emscripten platform selection, a yielding event-loop adapter and deliberate WebGL/shader/framebuffer/color handling. The SDL2-static SoLoud backend opens and unpauses an audio device. A null backend is supplied, but the selected SoLoud project chooses SDL2-static rather than null. Silent development requires an authored build/startup decision; an existing null source file alone does not prove muting. No browser build, startup or gameplay result is established here.

The readme licenses supplied configuration, scripts and rooms like the source while expressly excluding missing retail content from that grant. It describes loose-file loading as an alternative to retail `.cpk` packages. That is a useful content interface, not a complete ROM-free game. No `.cpk`, original mesh, texture, animation, font, audio or other excluded media was imported. A release still needs a complete independently authored content pack, original text and maps, provenance manifest, working resource serialization/loading and gameplay/persistence verification. Native tools also require adaptation before their documented output can be relied upon on another platform.

**Next gate:** construct a private, source-only Emscripten compile probe from the 2019 release, resolve the platform/render/audio adapters and record exact selected dependency notices before producing an independently authored playable content pack. Eldritch remains a candidate; no code-grant blocker is inferred from its excluded retail assets, and no integration eligibility or playability is yet claimed. Keep its source-port classification separate from the decompilation milestone.

## Raptor: released source and reconstruction-derived port

`skynettx/dosraptor`, `4403569505c215c6cebe02cc3344e670499def1d`, 340 stars, describes the original DOS v1.2 source release. The [readme](https://github.com/skynettx/dosraptor/blob/4403569505c215c6cebe02cc3344e670499def1d/README.md) credits Scott Host and the contributors, substitutes Apogee Sound System/APODMX for proprietary DMX, and declares GPL-2.0-or-later. It documents Watcom C/TASM DOS builds. Original published source is not decompilation work; removal of DMX does not convert the rest of the code to permissive terms.

`skynettx/raptor`, `746c35a256bfa2afc6732c7923be9e2e777d6bf0`, 130 stars, is a separate SDL2 implementation. Its [readme](https://github.com/skynettx/raptor/blob/746c35a256bfa2afc6732c7923be9e2e777d6bf0/README.md) identifies a reverse-engineered codebase from nukeykt; this differs from the original-source DOS release above. It declares GPL-2.0-or-later, with GPL3 for the Android route. Support for a modernized game does not independently establish additional permissive grants for reconstructed code or original media.

The [CMake recipe](https://github.com/skynettx/raptor/blob/746c35a256bfa2afc6732c7923be9e2e777d6bf0/CMakeLists.txt) selects C/C++11, SDL2 and desktop/Android platform-specific targets, including ALSA or native MIDI APIs. No Emscripten target is selected in this recipe. TinySoundFont has a separate MIT notice; the selected textscreen implementation is GPL-2.0-or-later. A suggested external soundfont is another asset whose grant must be checked separately. No dependency binary, soundfont or original audio was fetched.

The port explicitly requires original shareware/full GLB assets from v1.2 or later; older data is incompatible. Neither a code license nor the word shareware clears those original graphics, sounds, text, maps and animations. No complete independent replacement pack is documented here. **Blocked under the current scope:** GPL is outside the accepted permissive route, original content is required, and a browser gameplay build remains unverified. Replacement art alone would not resolve the code-license gate. Count these repositories as one game identity.

## Ken's Labyrinth: inherited restrictions survive the MIT port notice

`EXL/KenLab3d`, `3f6a18272f41c027870f2207e63703d05be624d6`, 12 stars, is an Android port of LAB3D/SDL. Its root [MIT notice](https://github.com/EXL/KenLab3d/blob/3f6a18272f41c027870f2207e63703d05be624d6/License.md) names the Android contributor. The selected [LAB3D/SDL readme](https://github.com/EXL/KenLab3d/blob/3f6a18272f41c027870f2207e63703d05be624d6/docs/KenLab3d/ReadMe.txt) reproduces Ken Silverman's source terms: derivatives may be distributed only over the Internet, free of charge, without commercial exploitation, with the required attribution. These inherited restrictions prevent treating the combined game code as MIT.

The separate [data notice](https://github.com/EXL/KenLab3d/blob/3f6a18272f41c027870f2207e63703d05be624d6/kenlab3d/src/main/assets/KenLabData/README.TXT) permits free copying of the original full-game release subject to no sale for profit and retention of its original files and notices. This is restricted freeware, not CC0 or an unrestricted derivative-asset grant. Only that textual notice was fetched from the data directory. The [original developer's page](https://advsys.net/ken/klab.htm) separately links source and data and directs readers to the source license; it does not turn the Android contributor's MIT declaration into a relicensing of either.

The selected Android recipe uses SDL2, LodePNG and GLUES, linking GLES1/GLES2 and Android logging. LodePNG's selected notice is zlib-style; GLUES declares SGI Free Software License B 2.0; SDL's copying notice is separate. Those grants do not supersede the inherited game restriction. There is no selected Emscripten build or independent browser-content pack. This is an original-source port, not a matching decompilation or clean-room-certified engine recreation.

The cached lead `kandowontu/kens-labyrinth-native-windows` returned GitHub API 404. No pin, current license, build completeness or gameplay claim is established for it. It would be another implementation of this same identity, not an additional game. **Blocked under the current scope:** inherited noncommercial code terms, restricted original data and an unverified browser route. Reopen only with an acceptable whole-code grant and a viable independently authored content/browser route.
