## CannonBall: the actual licence is restrictive

`djyt/cannonball`, pin `27493ebf62be3498dff93ed6a45e8e2db819bae1`. Its [README](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/README.md) describes rewriting original 68000 and Z80 assembly into C++. This supports a decompilation-derived rewrite classification; it does not establish matching output, independent clean-room history or an original rights-holder grant.

The actual [code licence](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/docs/license.txt) prohibits sale and use in commercial products or activity. Modified redistributions must supply the complete source of components used by the binary, subject to its stated system-component exception. This is a noncommercial source licence, not MIT or a permissive BSD grant. That code gate remains even if independently authored assets are supplied.

Dependencies have separate origins. The selected [YM2151](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/src/main/hwaudio/ym2151.cpp) and [SegaPCM](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/src/main/hwaudio/segapcm.cpp) files identify older MAME-derived implementations and reference a MAME licence URL. Their historical grants were not closed by reading the modern MAME licence, and no blanket permissive dependency clearance is asserted. SDL2, Boost headers and the exact selected host/compiler components also need a build-specific inventory. Chip emulation does not by itself make the reconstructed gameplay a full CPU emulator.

[ROM loading](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/src/main/roms.cpp) requires master/slave program ROM data as well as tile, road, sprite, sound-program and sample data. Replacing a few visible images would not remove these inputs. The [native entry point](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/src/main/main.cpp) loads the ROM set before entering a blocking SDL loop. [CMake](https://github.com/djyt/cannonball/blob/27493ebf62be3498dff93ed6a45e8e2db819bae1/cmake/CMakeLists.txt) selects SDL2 and optional render/DirectX paths; no Emscripten target was found in the pinned tree. That is a scoped target search, not proof that a browser port is impossible. Reopen only with an accepted code-grant route, exact dependency selection, complete independent runtime data and a working browser adaptation.

## Need for Speed: wrapper and recompilation grants are separate

`zaps166/NFSIISE`, pin `66cbaf47fd77e833c9331b81f6c1e52aff56913f`. The [MIT notice](https://github.com/zaps166/NFSIISE/blob/66cbaf47fd77e833c9331b81f6c1e52aff56913f/LICENSE) is explicitly limited to wrapper code by the [README](https://github.com/zaps166/NFSIISE/blob/66cbaf47fd77e833c9331b81f6c1e52aff56913f/README.md). It is not permission to redistribute translated retail program logic, original game content or every dependency.

The exact gitlinks are `zaps166/NFSIISE-ASM` at `7b8ad75fddac7ce6cd13e2d4b482128925e2a13f` and `zaps166/NFSIISE-CPP` at `7607d07ea7471b0547d42fb9bb71e0c339f98a0c`. Each pinned tree contains one large translated game source file, respectively 3,679,940 and 5,722,005 bytes, with no separate grant notice identified in those trees. Those payloads were not downloaded or reviewed. A component boundary is not a licence extension from the wrapper.

[Build selection](https://github.com/zaps166/NFSIISE/blob/66cbaf47fd77e833c9331b81f6c1e52aff56913f/compile_nfs) distinguishes x86 Yasm from the C++ translation and Android/GLES paths. The documented non-x86 contract is 32-bit little-endian. This is not a demonstrated wasm32 port. Original Special Edition `fedata` and `gamedata` remain required; no independently authored full cars/tracks/interface/audio/text pack was established. Selected language/icon payloads were excluded. Exact SDL2/OpenGL/toolchain closure and browser scheduler, filesystem, networking and save behavior remain unverified.

`motor-dev/nfs-recompiled`, pin `77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a`, is another route for NFS II SE and III HP. Its [generator](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/disassemble_nfs2se.py) and [virtual CPU structure](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/include/cpu.h) support static recompilation preserving original instruction-state semantics. Generated C++ is not evidence of handwritten source reconstruction or independently authored game logic. No overall project/generated-game grant was identified in the pinned tree. Original executables/DLLs for generation and original game data remain requirements.

The README warns that its text and CMake are mostly AI-generated. Actual [CMake](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/CMakeLists.txt) and the [thread backend](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/src/lib/thread.cpp) use SDL3 despite the README's SDL2 wording. The separately read [SDL3 notice](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/sdl3/include/SDL3/SDL_copying.h) is zlib-style; it does not license the game or generated code. Vendored `pefile.py` has a copyright statement but no embedded grant identified in the selected file; its tool permission needs separate resolution. Native [memory management](https://github.com/motor-dev/nfs-recompiled/blob/77ebdb3b6a21925ccfc4fc4c1d712abec3e1945a/src/lib/memmap.cpp) uses `mmap`/`mprotect` or Windows allocation/protection. Threads, desktop OpenGL and an optional Linux/NASM x87 path require deliberate browser adaptation; the optional assembly path is not claimed to be mandatory. Bundled SDL binaries were not fetched. No build or gameplay claim is made.

## Tomb Raider: a standalone engine and an injector are different

`LostArtefacts/TRX`, pin `c97a83f06183f3b9b8835f004048649b406bc7f5`, describes a unified reimplementation using decompilation and replacements for proprietary components. [COPYING](https://github.com/LostArtefacts/TRX/blob/c97a83f06183f3b9b8835f004048649b406bc7f5/COPYING.md) is GPL3. Its desktop complete-game claims are upstream statements, not local tests. [Installation](https://github.com/LostArtefacts/TRX/blob/c97a83f06183f3b9b8835f004048649b406bc7f5/docs/trx/INSTALLING.md) imports original game files, with some demos/expansions offered as downloads. Availability, freeware descriptions and custom-level support do not establish an independently licensed replacement campaign. None was downloaded.

[Meson](https://github.com/LostArtefacts/TRX/blob/c97a83f06183f3b9b8835f004048649b406bc7f5/src/meson.build) selects FFmpeg libraries, SDL2, GLEW, PCRE2, Lua, zlib/OpenGL and an optional Windows dwarfstack component. Exact versions, codec/configuration selection and grants remain unclosed. Only the dwarfstack wrap metadata was read, not its implementation or archive. Documented platforms are Windows, Linux and macOS; no Emscripten target was found in the pinned tree. Reopen after an accepted project licence route, selected dependency review, full independently authored model/animation/world/interface/text/audio content and browser gameplay/save verification.

`Arsunt/TR2Main`, pin `f38bc90438e21e8a37e915a812cade52efce1d68`, is specifically an incremental decompilation DLL injecting a patched original executable. [Source](https://github.com/Arsunt/TR2Main/blob/f38bc90438e21e8a37e915a812cade52efce1d68/TR2Main.cpp) declares GPL3-or-later. [Code::Blocks selection](https://github.com/Arsunt/TR2Main/blob/f38bc90438e21e8a37e915a812cade52efce1d68/TR2Main.cbp) references the original host executable and legacy DirectX SDK/import libraries. The [JSON parser](https://github.com/Arsunt/TR2Main/blob/f38bc90438e21e8a37e915a812cade52efce1d68/json-parser/LICENSE) has a separate BSD-2-Clause notice; that does not change the injector or SDK terms. Original levels remain required, and the README's freeware Golden Mask description does not clear the pack for this permissive intake. Reopen only with acceptable code/dependency grants and a standalone browser runtime using independent complete content. Injector startup would not satisfy that gate.
