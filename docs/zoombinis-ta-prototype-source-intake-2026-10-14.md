## Total Annihilation: MIT tooling does not license the game source

The pinned [LICENSE](https://github.com/HectorBailey/byte-tactics/blob/97d7ac59b460417bcdfa629cf90da99f31818c65/LICENSE) expressly limits MIT to `tools/` and says reconstructed `src/` is not offered under any licence. The [README legal section](https://github.com/HectorBailey/byte-tactics/blob/97d7ac59b460417bcdfa629cf90da99f31818c65/README.md) makes the same separation. A permissive toolkit cannot establish distribution permission for the game functions it reconstructs. Replacing models, maps and sound would not remove this code blocker.

Upstream reports all 3,267 game functions matching and a reconstructed whole executable. Those results were not repeated. Current [placement code](https://github.com/HectorBailey/byte-tactics/blob/97d7ac59b460417bcdfa629cf90da99f31818c65/tools/place.py) and [linking documentation](https://github.com/HectorBailey/byte-tactics/blob/97d7ac59b460417bcdfa629cf90da99f31818c65/docs/linking.md) describe `--no-orig` replay from a recorded layout, compiled data, compiler runtime members and resource tooling. The current documentation says no code gap is copied; its earlier measurement phases must not be misread as a current incomplete-code result. This screen does not certify that claim or equate binary-exact reconstruction with an authorized distribution.

The whole-image route still distinguishes Cavedog art/icon/cursor resources, recovered source-side data, Microsoft VC++ 5 runtime libraries and generated PE metadata. `--no-orig` is not evidence that all inputs are independently authored or permissively licensed. The original Windows host and libraries, including native import boundaries, are not a browser runtime. No verified WASM build or complete independent resources were established.

The selected [setup script](https://github.com/HectorBailey/byte-tactics/blob/97d7ac59b460417bcdfa629cf90da99f31818c65/tools/setup_toolchain.sh) fetches VC++ 5 Professional and Service Pack inputs and can copy an installed game executable. It was read, not executed. No proprietary toolchain, game executable or matching output was obtained. Legacy CRT/import-library selection and grants would need separate treatment for any authorized portable route.

Reopening gates: obtain an acceptable game-source distribution grant/provenance route, close selected native/library and recovered-data scope, author a complete independent content pack, implement a browser host and toolchain route, then verify muted normal gameplay, persistence and shutdown. Alternative Total Annihilation engines are not this matching project and must be separately classified/audited; no broad recreation expansion was started here.

## Zoombinis: no-disc packaging still ships converted retail resources

The [README](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/README.md) documents Borland C++ 4.5 reconstruction, approximately 2,100 game/engine functions, a mixture of matched functions and portable stand-ins, and modern native/Web targets. No project-wide LICENSE/COPYING/NOTICE grant was identified in the inspected tree or selected project metadata. The legal section reserves original names/artwork and describes preservation/interoperability; that is not a permissive licence for the reconstructed game or the complete project. Third-party component grants are separate.

The technical browser route is real source selection, rather than CPU emulation inferred from a web page. [CMake](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/port/CMakeLists.txt) compiles decompiled C++ and selected replacement glue with C++17, miniwin over SDL2 and [Emscripten fibers/yielding](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/port/host/emscripten.cpp). It uses Asyncify, IDBFS, a 1 MiB stack, 128 MiB initial memory with growth and an exit-runtime branch. [The driver](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/src/zbtools/port.py) pins Emscripten 6.0.10. No SDK setup, compilation or hosted gameplay was run here.

The claim that the port can build without game files supplied by the operator has a specific explanation: the repository already contains converted original resources. [Web packaging documentation](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/docs/src/port/web.md) packages the CD data regenerated from `assets/`, executable-derived icons, original installed support files, font and roster data, plus a SoundFont. Avoiding an external ISO at build time does not make these an independently authored replacement pack. This is not recorded as a runtime requirement to supply the original disc when the packaged data is already present. None of that retail media was downloaded in this screen.

The README describes Cornerstone as free for personal use and included on a noncommercial basis. That is a separate concrete content restriction; a code or third-party font renderer licence does not clear the font. No independently authored complete character/animation, puzzle/script, dialogue/text, interface/font, audio/music or intro resource set was established.

Selected component notices were fetched at the exact build references: [stb](https://github.com/nothings/stb/blob/2c980bb59875b0d32144a71867fbdebb2f77cd20/LICENSE) offers MIT or public-domain/Unlicense alternatives; [TinySoundFont](https://github.com/schellingb/TinySoundFont/blob/853a0a171759f1ddba0de1442133a75912bbeffa/LICENSE) carries MIT with its SFZero attribution. [GeneralUser GS v2.0.3](https://github.com/mrbumpy409/GeneralUser-GS/blob/684543d5e5efaef08d02be50dcda8d552478fa60/documentation/LICENSE.txt) grants broad complete-work use but explicitly acknowledges uncertain origins for some samples. These are notice reads, not an audit of every component file or proof of the game's grant. SoundFont bytes were not fetched; its notice does not clear retail MIDI. Actual Emscripten SDL port and SDK/runtime closure remain unverified.

The [pre-start script](https://github.com/slippedandmissed/zbtools/blob/e3c55c74a046c4925097e1bf13a2554ba61b292e/port/web/pre.js) restores IndexedDB and waits for a Play click that also enables audio. It is not an accepted silent DecompGames host; a future release must enforce sound off. Source CMake defaults debug tooling on, whereas the packaging driver documents a player build without it. Debug scene jumps, party/level edits and generated tests must not be presented as ordinary-control gameplay acceptance.

Reopening gates: establish the complete selected source/glue/header grant, replace or obtain exact permissive grants for all retail/personal-use/uncertain resources, close dependency/toolchain notices, package without debug cheats, and test the independent game through normal puzzles, losses/retry, saves and full stop/unload while muted. No current release or clean-room claim is made.

This is a reconstruction-informed port/recreation, with no matching-binary proof established here.

No complete independent art/animation/font/scripts/maps/audio package was established. The README's installer can fetch a disc image automatically; it was not executed and no image was acquired. Original-format parsing does not imply that a bundled original CD is licensed or ROM-free replacement gameplay.

The selected [desktop backend](https://github.com/openprototype-game/openprototype/blob/9085d81a67612c8bd52f4863b7d4089377935be4/crates/backend/Cargo.toml) uses Rust 2024, winit 0.30.13, wgpu 29 and optional rodio. An older comment mentions pixels while actual dependencies use wgpu; actual manifest selection governs. Library browser capabilities alone are not a verified game WASM host, disc-file bridge, save or teardown result. Exact Cargo.lock/transitive source and notice closure was not undertaken after the initial licence blocker.

Disc-dependent tests are explicitly ignored without their feature/input; those ignored tests were not counted as passing and no tests were run here. Reopen only if the accepted code route changes, followed by independent complete content, selected dependency audit and a proven browser host with normal muted gameplay/persistence/shutdown.
