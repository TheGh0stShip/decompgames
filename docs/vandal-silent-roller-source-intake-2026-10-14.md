## Whiplash / Fatal Racing — ROLLER

[FatalDecomp/ROLLER](https://github.com/FatalDecomp/ROLLER/tree/d5b122129a25ea9d186e03506a84416c68f25f38), pin `d5b122129a25ea9d186e03506a84416c68f25f38`, had 88 stars and 750 tree files at review. Its README describes reverse engineering and replacement of DOS interfaces, and directs instruction-matching work to the separate ROLLER-matching project. Classify this repository as a reconstruction-derived, partially rewritten port; its separate matching lineage is upstream documentation, not a byte-matching test performed here.

The [root notice](https://github.com/FatalDecomp/ROLLER/blob/d5b122129a25ea9d186e03506a84416c68f25f38/LICENSE.md) is GPL-3.0, outside this intake's current permissive-code route. It does not establish a separate original-rightsholder grant for every reconstructed unit. Dependencies were checked separately: the selected Web link recipe names `libroller.a`, `libSDL3.a`, `libcdio.a` and `libadlmidi.a`. The pinned libcdio [driver notice](https://github.com/Zizin13/libcdio/blob/4b5dda49f9c4fd844aaf97012c3157e5d2aa634a/lib/driver/cdio.c) and vendored [libADLMIDI header](https://github.com/FatalDecomp/ROLLER/blob/d5b122129a25ea9d186e03506a84416c68f25f38/external/libadlmidi/include/adlmidi.h) both declare GPL-3.0-or-later. WildMIDI appears in native configuration but is gated out when `bWasm` is true; it must not be reported as selected merely because the README lists it. Full transitive and SDK closure was not audited after these gates failed.

There is concrete browser potential: [build.zig](https://github.com/FatalDecomp/ROLLER/blob/d5b122129a25ea9d186e03506a84416c68f25f38/build.zig) defines `zig build web`, compiles `wasm32-emscripten`, uses IDBFS and a browser shell, and includes an Emscripten bridge source. However, its preparatory step automatically fetches the original Whiplash demo, verifies its FATDATA tree, and preloads it at `/demo/fatdata`. Supplying `demo-assets-path` still requires that same verified demo tree; it is not an arbitrary independent-content switch. The [fetch script](https://github.com/FatalDecomp/ROLLER/blob/d5b122129a25ea9d186e03506a84416c68f25f38/scripts/fetch_demo_assets.py) was read, never executed. A freeware description does not establish CC0 or permission for our intended package. No complete independent car, track, UI, text or sound campaign was established.

**Disposition:** blocked by the current code route, separate selected copyleft dependencies and original-demo content. Reopen only for changed accepted code terms/rights evidence and a complete independently authored content path. Existing upstream Web availability is not our gameplay acceptance.

## Vandal Hearts — native PC port

[HalmyLyseas/VandalHearts-PcPort](https://github.com/HalmyLyseas/VandalHearts-PcPort/tree/14552fffa0e0b47e02b57592e274fc6e7a649923), pin `14552fffa0e0b47e02b57592e274fc6e7a649923`, had 48 stars and 505 tree files. It documents a native C port based on matching US/Japanese decompilations, with reimplemented PlayStation interfaces. It is a decompilation-derived port, not a generic emulator or a matching verification performed here.

Its [NOTICE](https://github.com/HalmyLyseas/VandalHearts-PcPort/blob/14552fffa0e0b47e02b57592e274fc6e7a649923/NOTICE) explicitly restricts GPL-2.0 to original port work and excludes the reconstructed Konami game code, unit/animation/sprite tables, and reference subtitle lines. Thus even accepting GPL or replacing external pictures would leave the inherited-code permission gate unresolved. The same notice says release binaries embed executable static data, BIOS-derived kanji and reconstructed tables; do not mirror binaries based on a source-tree claim that media is excluded. Its optional HD pack upscales original art/movies and is not independently authored replacement content.

The inspected [native CMake](https://github.com/HalmyLyseas/VandalHearts-PcPort/blob/14552fffa0e0b47e02b57592e274fc6e7a649923/platform/pc/CMakeLists.txt) requires SDL2, OpenAL, Threads and platform graphics, with optional WebP/FFmpeg paths. These remain separate dependencies, with exact release closure unverified. Generation uses the original regional PS-X executable and Sony font input; maps, scripts, dialogue, audio and movies still come from the visitor's disc. No independent complete campaign or verified Emscripten adaptation was established. A WebP decoder is not evidence of a Web build.

**Disposition:** blocked by explicit excluded inherited-code/table rights, port-only copyleft scope, original executable/font/disc content and unverified browser/dependency adaptation. Upstream full-playthrough claims were not reproduced here. PsyQ isolation claims remain upstream assertions, not our clean-room certification.

## Silent Hill — native PC port

[SlickAmogus/silent-hill-decomp, pc-port](https://github.com/SlickAmogus/silent-hill-decomp/tree/3116b58c8d932f016ca5734a70766ac2ffcd0e98), pin `3116b58c8d932f016ca5734a70766ac2ffcd0e98`, had 675 stars and 2,464 tree files. Its documented runtime compiles reconstructed C with native console-interface replacements; classify it as a decompilation-derived port rather than static recompilation or general emulation.

[COPYRIGHT.md](https://github.com/SlickAmogus/silent-hill-decomp/blob/3116b58c8d932f016ca5734a70766ac2ffcd0e98/COPYRIGHT.md) distinguishes GPL-3.0-or-later original port/additions from inherited decompilation material, to which it expressly grants no license. It separately lists third-party components and excludes notification sounds and derivative fan-translated dialogue from the port grant. Those sound files were not fetched. A no-game-data claim in the README does not clear these specifically identified bundled items.

The [CMake recipe](https://github.com/SlickAmogus/silent-hill-decomp/blob/3116b58c8d932f016ca5734a70766ac2ffcd0e98/pc_port/CMakeLists.txt) has native SDL2/PsyCross/OpenGL, RetroAchievements and optional FFmpeg paths plus static/dynamic map-overlay configurations. The notice identifies OpenAL Soft and FFmpeg derivations with their separate terms; selected transitive closure and PsyCross permissions remain unaudited. Neither native platforms nor an optional static-overlay mode establishes working browser adaptation. Running requires the original PlayStation disc; no independently authored complete models, animation, maps, scripts, dialogue or audio pack was established.

**Disposition:** blocked by explicit lack of a reconstructed-code grant, copyleft port scope, original disc/content dependencies, separately excluded bundled content and unverified browser/dependency closure. Independent replacement graphics alone cannot resolve these gates.
