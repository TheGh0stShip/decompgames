# Vector Duel private gameplay candidate

October14: the GLFighters source-port lead now has a working, independently authored Foundry Deck arena and silent browser player. **Not integrated or deployed.** Catalog88 and the strict additional-decompilation milestone4/5 remain unchanged: this candidate is a developer-released source port, not a decompilation, emulator or clean-room certificate.

The [original-author code permission evidence and source pins](glfighters-overgrowth-source-intake-2026-10-14.md) remain separate from content and dependency grants. No upstream `port/data`, retail archive, ROM, original graphics/motion/map/font/audio or purchased game installation was used. The [own content manifest](../experiments/vector-duel/provenance.json) records173 independently authored CC0 files:24 meshes,45 action animations,71 textures, one glyph atlas, one arena and31 synthesized PCM clips. File hashes, binary counts/dimensions and native format bounds pass. Own glyphs reuse our Beacon Relay CC0 definitions. The edition deliberately has a silent backend; its authored PCM is not played.

[Normal-input browser evidence](vector-duel-private-gameplay-2026-10-14.json) records157 native state samples. The player moves, rises toY8.4104 fromY0.5 and lands. Three practice rounds defeat the native opponent and retry. The attacking opponent damages and defeats the player in a separate duel round. Focus loss pauses simulation and releases held input; Stop freezes the native tick count. Completed-round totals survive closing and reopening the browser. No native health, actor position, animation, RNG or save state is written by the tests. The journal stores round totals only; an unfinished match restarts on reload. No native world/map-save capability is claimed.

[Loading acceptance](vector-duel-private-loading-2026-10-14.json) covers missing JS/WASM/data, unavailable WebGL and an invalid journal. Failure messages/reload controls are shown, and invalid counters reset safely. Expected compiler fetch/abort errors remain recorded; they are not presented as zero-error successful gameplay. Startup polling is gated until runtime initialization, WebGL failure is reported promptly and the host is scoped to avoid emitted-runtime name collisions. All tests are muted; all players and servers close afterward. Audible playback is unavailable and unverified.

The [strict private build](vector-duel-private-build-2026-10-14.json) uses eight native game units plus an own observer/control adapter, a real69-object rebuilt gl4es and SDL2. SDL_mixer and its codec stack are excluded. SDL's dormant audio support is still present among selected members; video-only initialization and a sound backend replacement prevent playback.

The renderer's historical SGI platform header was detected separately from its MIT root. The current candidate uses a hash-recorded Khronos2017 Apache2 platform header from the current SDK through an include overlay; selected compiler inputs contain no historical SGI header. Earlier source-only and gameplay builds remain preserved privately. A source-selection error in the first overlay rebuild was rejected by the strict linker and corrected with source/object-name and uniqueness assertions; no unresolved-symbol allowance, rendering stub or fabricated game state was used.

[Runtime mapping](vector-duel-runtime-mapping-2026-10-14.json) identifies all375 extracted members across10 archives:64 renderer,80 SDL2 and231 system members. Compiler dependencies record503 inputs; a build-only observer maps438 emitted JavaScript definitions to17 source libraries. An observed duplicate link produces identical WASM/data and normalized JavaScript. This is source-origin evidence, **not complete distribution-license clearance**. Exact imported helper, system-header, SDK template and preload-generator notices still need review and preservation. The private build scripts still depend on the retained source workspace; portable source packaging and an independent rebuild replay remain release gates, followed by final package and local/production acceptance.
