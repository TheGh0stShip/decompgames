This is outside the current permissive-code intake route. Native reconstruction/recreation classification does not establish an independently reproduced matching decompilation or clean-room process.

The native config supports SDL/SDL2, optional image libraries, Munt and FluidSynth; exact selected dependency versions/grants/codec closure require a separate release audit. OS/2's documented MIDI route requires separately supplied CM32L ROMs. Neither engine GPL nor MIDI-emulator code clears those files. Reviewed configure/config.lib lists native OS backends, with no identified browser game recipe. Browser scheduler/input/display/files/save adaptation and silent audio completion behavior remain untested. **Blocked for current code route, original executable/content inputs, independent full content and unverified browser/dependency closure.** Existing historically accepted GPL entries remain unchanged.
