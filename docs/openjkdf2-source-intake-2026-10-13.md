Code gate: [actual LICENSE](https://github.com/shinyquagsire23/OpenJKDF2/blob/d40b9451aa319fd4c37f4e784ce62d9d30a12927/LICENSE.md) supplies a short permissive grant for OpenJKDF2 contributor software while separately naming Lucasfilm game/property copyright and distinct third-party licences. It is not an MIT whole-distribution declaration or evidence of rights-holder permission for all reconstructed retail game code. Reviewed methodology makes that inherited-code scope a real unresolved intake gate; no assertion that upstream is unlawful. Do not clear the gate solely from the root grant or a functioning public demo.

Content gate: original licensed game data required by README. Browser instructions copy `episode/` and `resource/` into wasm_out; the actual Web packaging command preloads that directory. No documented complete CC0/independent replacement set established for maps, scripts, textures, models, animations, text/UI, audio/video. Original demo availability is not permissive asset permission. User-authorized content replacement can proceed only after code/dependency eligibility, with a complete authored manifest; a small synthetic room would not be a finished Jedi Knight release.

Browser gate: upstream has Emscripten/WebGL2 support, but [BUILDING](https://github.com/shinyquagsire23/OpenJKDF2/blob/d40b9451aa319fd4c37f4e784ce62d9d30a12927/BUILDING.md) describes the WASM target as semi-supported and names v0.2.0 as its last tested tag. Current [plat_wasm.cmake](https://github.com/shinyquagsire23/OpenJKDF2/blob/d40b9451aa319fd4c37f4e784ce62d9d30a12927/cmake_modules/plat_wasm.cmake) selects SDL3, WebGL2, Asyncify, IDBFS and native-style GL/GLEW/OpenAL link inputs. Its comments explicitly identify missing SDL3_mixer support/music playback breakage after API migration. Thus documented browser potential exists, but this current revision is not a verified browser gameplay release here. No inference that it is impossible.

Dependency gate: selected Web target includes [plat_feat_full_sdl2](https://github.com/shinyquagsire23/OpenJKDF2/blob/d40b9451aa319fd4c37f4e784ce62d9d30a12927/cmake_modules/plat_feat_full_sdl2.cmake), enabling LIBSMACKER/LIBSMUSHER/OpenAL, and then disables PhysFS/curl/GameNetworkingSockets. Inherited libsmacker [COPYING](https://github.com/shinyquagsire23/OpenJKDF2/blob/d40b9451aa319fd4c37f4e784ce62d9d30a12927/src/external/libsmacker/COPYING) is LGPL2.1, separately from the root permissive grant. Exact linked object/library closure, codec removal or equivalent independently licensed alternatives, toolchain and all remaining dependency notices must be audited. Submodule pins are recorded, not blanket clearance of SDL/OpenAL/etc. A target flag is not a complete actual-link inventory.
