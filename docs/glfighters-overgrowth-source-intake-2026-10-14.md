# GLFighters and Overgrowth source intake

October14 source-only intake: two nonduplicate released-source games, catalog88 and strict additional-decompilation milestone4/5 unchanged. Neither is a decompilation or emulator. GLFighters provides a practical new private engineering lead; Overgrowth has substantially larger content/runtime gates. No original media, game archive, player or purchased installation was downloaded or run.

## GLFighters: documented author permission and a successful source-only link

[wedaly/GLFighters-SDL](https://github.com/wedaly/GLFighters-SDL/tree/4dffdbd665767baae87bec749f18d689ab53c534), pin `4dffdbd665767baae87bec749f18d689ab53c534`, seven stars. This is Will Daly's SDL/native/WASM port of David Rosen's2001 Classic Mac OS game. The [MIT notice](https://github.com/wedaly/GLFighters-SDL/blob/4dffdbd665767baae87bec749f18d689ab53c534/LICENSE) names both authors. More significantly, the [porter's publication account](https://devnonsense.com/posts/glfighters/#source-code-and-demo) explicitly reports David's permission to publish the source under MIT. This is a documented author-permission report, not an independently inspected private letter, asset grant or clean-room certificate. The licence history only adds David's attribution; that commit alone would not establish permission.

The [WASM recipe](https://github.com/wedaly/GLFighters-SDL/blob/4dffdbd665767baae87bec749f18d689ab53c534/Makefile) uses SDL2/mixer, gl4es and `FULL_ES2`, preloading the entire original `port/data` directory. Upstream CI selects Emscripten3.1.70. The upstream demo was not opened, mirrored or counted as our acceptance test. Original Mac StuffIt source/game archives, animations, textures, models, maps and sounds were excluded from downloads. The code permission does not clear those assets.

Thirty-two allowlisted game/build/header/notice files were retained privately. All eight unchanged game translation units compile with Emscripten6.0.10 into verified WASM objects. The root recipe references a bundled prebuilt gl4es archive; it was not downloaded or reused. Instead, [ptitSeb/gl4es v1.1.6](https://github.com/ptitSeb/gl4es/tree/c9895df34cd466c23bc60c2bd3db3d87e98fcbe7), pin `c9895df34cd466c23bc60c2bd3db3d87e98fcbe7`, was rebuilt from198 allowlisted source/header/include/build/notice inputs. The library declares its separate MIT terms; imported headers/helper origins and the exact selected runtime still need closure rather than an all-MIT assumption.

The rebuilt archive contains69 unique compiled WASM-object members; all69 build objects have valid WASM magic. CMake4 required the `CMAKE_POLICY_VERSION_MINIMUM=3.5` compatibility override; an initially omitted textual `glesfuncs.inc` was added to the source inventory. No upstream source patch was needed. Native X11/EGL loaders and automatic initialization were disabled; static ES2/no-loader initialization matches the game's explicit context setup.

The eight original game objects **strict-link successfully** against the freshly rebuilt gl4es plus the selected SDL2/mixer runtime, with undefined-symbol errors enabled. Private JS211058bytes SHA256 `3a69b55fb46e89a159a19138b84715d00caf76ea13e5f674a1ec1daff5238f56`; WASM1467730bytes SHA256 `4ee9d24ad17a4e5b1331f07345c8993fdc307ea3515ff37df9bd274e52fc8793`. These are source-only probe artifacts, not a runnable accepted game or distributable content pack.

Failed alternative-backend probes remain preserved. Stock Emscripten legacy GL and FULL_ES2 cannot be enabled together. Removing FULL_ES2 still left gl4es aliases from the vendored headers. Recompiling against native Emscripten GL headers reduced the remaining link issue to `glLightf`, and local backend inspection showed attenuation parameters would abort even through `glLightfv`. No fake scalar stub, unresolved-symbol allowance or ignored rendering failure was used to obtain the final link; the final uses the real rebuilt gl4es backend and original game source.

## Independent-content contract and remaining release gates

Source loaders establish a concrete replacement path without reading original media:

- Models: big-endian vertex count followed by eight big-endian floats per vertex (UV, normal, position); bounded to1000 vertices. Independently authored geometry must include every selected model, including characters, equipment and arena pieces.
- Animations: big-endian frame count and three axes of per-frame joint/hip/rotation/speed integers. The loader contains fixed20-frame arrays and native animation/collision logic; it needs an explicit bounded authored contract and input validation before shipping. Forty-five animation identities are loaded at startup; retained original motion files are excluded.
- Maps:100×100 big-endian map/wall integer pairs, followed by sixteen spawn-coordinate pairs. `NormalMap` is the initial loader contract, not permission to reuse its original layout. Independently author arena geometry/spawns and the intended challenge.
- Textures/font:72 BMP paths selected by the native loader; original converted bitmaps and skyboxes are excluded. Own graphics, effects, glyph atlas, palettes and UI/text require provenance.
- Audio: the stock main initializes SDL audio and loads external WAV clips. The final edition must start silent and either use independently authored audio or deliberately implement a documented silent backend. No audible test or silent-player claim was made by this compiler probe.

Upstream README says map opening/saving is not implemented in this SDL port. Browser persistence therefore needs a deliberate supported design and full browser-restart testing, not an assumption that native map APIs already work. Stop/focus handling, loading failure paths, real normal-input combat/movement/death/restart and exact source/package reproduction also remain gates. Selected SDL2/mixer/Ogg/Vorbis, Emscripten/LLVM support and gl4es/header/helper notices require a release-specific audit. **Current status: code-permission-backed source-port engineering lead, strict source link passed; no complete independent content/runtime distribution or browser gameplay yet. Not integrated.**

## Overgrowth: official Apache source, independent total-conversion route

[WolfireGames/overgrowth](https://github.com/WolfireGames/overgrowth/tree/245fe4828631c84c0023d29d1525f5716ccb6106), pin `245fe4828631c84c0023d29d1525f5716ccb6106`, popularity recorded in the snapshot. The official developer repository's [README](https://github.com/WolfireGames/overgrowth/blob/245fe4828631c84c0023d29d1525f5716ccb6106/README.md) declares Apache2.0 for code unless otherwise noted and explicitly allows entirely new-asset total conversions. It requires written permission for redistribution of original assets. This is a developer-released source game/port candidate, not a matching decompilation or independent engine recreation.

[Compilation](https://github.com/WolfireGames/overgrowth/blob/245fe4828631c84c0023d29d1525f5716ccb6106/COMPILING.md) requires the purchased Data folder and an `AUX_DATA` path. No complete independent models, skeletons/animations, textures, maps/scripts, dialogue/UI/fonts or audio pack was established. Private deployment submodules are not prerequisites for an independent local source audit; none was initialized.

[CMake](https://github.com/WolfireGames/overgrowth/blob/245fe4828631c84c0023d29d1525f5716ccb6106/Projects/CMakeLists.txt) builds native desktop game/tools/worker targets and a broad graphics/audio/script stack. No reviewed native Web game recipe or rendering/storage/scheduler adaptation is established. Selected dependency notices were read separately: SDL's zlib-style terms, Ogg/Vorbis BSD notices and GLM terms do not relicense the separately included OpenAL library/copyleft notice or Oculus SDK. Oculus's pinned notice limits developer-content use to approved products; CMake also includes SDK source units, so a browser release needs a demonstrated exclusion/replacement and audited selected closure. Directory presence alone is not a complete link map, and optional Steam/telemetry support is not presumed enabled.

**Status: official permissive first-party source, but complete independent content, selected dependency exclusions/closure and a substantial unverified browser port remain blockers.** No build, game media, SDK/library binaries or player for Overgrowth was fetched/run. Apache root terms are not whole-distribution clearance.

[Raw source snapshots](glfighters-overgrowth-source-snapshot-2026-10-14.json) record242 selected text inputs across three pins, with original bytes preserved and explicit decoding for legacy notices. [Compiler/link evidence](glfighters-source-only-build-2026-10-14.json) records successful and failed stages. Claude-owned games and prior private ROM research remain untouched; no catalog/runtime upload, website deployment, gameplay/save/audio test or milestone increase occurred.
