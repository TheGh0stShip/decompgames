Each actual LICENSE.md and README declares **CC BY-NC-SA4.0 for the game release**, not MIT/permissive source. Noncommercial restrictions conflict with the current user-accepted permissive-code intake. No separate MIT grant for the underlying game code was established in reviewed material. Independently replacing assets cannot change those code terms. This gate excludes all three from current integration; their authors' permission is not being dismissed or substituted with an unproven retail-code allegation.

Content is separate: the native CMake builds copy `Data` to their output and the game repositories credit original artwork/music. No documented CC0 full content pack or independent replacements reviewed. The declared restricted game-release licence is not converted into CC0 by source availability. No media/executable downloaded. If code criteria later change, content and notices still require per-file/selective review before shipping.

Dependencies are separate: all three select Pomme submodule `69ee58bd06d4e9ab76b472c15ca5b6e06672be73`. Its [actual notice](https://github.com/jorio/Pomme/blob/69ee58bd06d4e9ab76b472c15ca5b6e06672be73/LICENSE.md) states MIT except listed components, including LGPL2.1 FFmpeg-derived IMA4/MACE/Cinepak code, other component notices, Boost/span and CC0/minimp3. This is a licence inventory observation, not proof which components reach a particular binary. Reviewed game CMake sets POMME_NO_MP3/POMME_NO_VIDEO, SDL3 and native OpenGL; selected audio/component closure and exact framework/toolchain notices remain unaudited. Do not label the entire distribution MIT just because the platform shim mostly is.

Browser gate: upstream build docs reviewed here describe macOS/Windows/Linux, SDL3 and OpenGL, not a tested browser target. Source-port status or SDL compatibility alone does not establish a yielding main loop, WebGL backend, filesystem/save behavior or browser gameplay. No build/player launched; browser feasibility remains unverified rather than declared impossible. Code eligibility fails before this engineering work is authorized as a current release candidate.
