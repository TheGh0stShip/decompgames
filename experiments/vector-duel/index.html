About this edition

A source port of David Rosen’s GLFighters, via Will Daly’s SDL port, with independently authored robot meshes, motion, pixels, glyphs and arena. This is a private release candidate. Source and runtime notices are still under review. Original game media and ROMs are excluded. Audio is disabled in this edition.
