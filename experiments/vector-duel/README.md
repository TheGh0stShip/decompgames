# Vector Duel Foundry Deck

An independently authored Foundry Deck robot arena using David Rosen's GLFighters via Will Daly's SDL source port. This is a developer-released source port with replacement content, not a decompilation, emulator, commercial campaign or clean-room certificate. The [release receipt](../../docs/vector-duel-release.json) and [runtime review](../../docs/vector-duel-runtime-review-2026-10-14.md) identify the published edition and remaining limits.

The source permission report, source pins and original-media exclusion are documented in [the source intake](../../docs/glfighters-overgrowth-source-intake-2026-10-14.md). The native source is MIT under its retained author notice; the renderer, SDK and helpers have separate terms. Own build/browser/observer/generator code is MIT. Own glyph pixels, meshes, action poses, textures, map and synthesized PCM are CC0; asset grants do not relicense code.

The historical `build.py`, `rebuild-renderer.py` and `audit-candidate.py` probes use the privately retained source workspace and Emscripten6.0.10 on this Windows host. The published corresponding-source ZIP contains selected source, own content generator, full notices, hashes and the portable `build-source.py` recipe. That recipe is intended to run inside the extracted archive with an externally supplied SDK and a fresh output directory. It compiles69 real renderer units and9 native game/own units, regenerates173 content files and verifies their hashes. The SDK manages standard/SDL objects; a whole-SDK independent rebuild is not claimed. Two archive extractions produce identical WASM/data and normalized JavaScript.

Run the generator, renderer rebuild and native build with Python3. Run `test-browser.cjs` and `test-loading.cjs` with Node from the repository root, where Playwright is installed. Tests launch muted headless Edge and close contexts/servers in `finally`. They record normal-input movement, actual jump height/landing, native combat health/defeat/retry, an attacking-opponent result, focus pause/input release, full-browser-restart journal persistence, Stop and negative resource/WebGL/storage handling. No actor, animation, health or RNG state is written by tests. `audit-candidate.py` consumes compiler/linker evidence and a separately observed duplicate link; it does not certify whole-distribution licensing.

The journal stores completed-round totals only. Unfinished native matches restart on reload. Native map saving is not implemented upstream and is not claimed here. Changing opponent mode restarts the native round; changes to mode during a round prevent credit until a new native round. Practice and attacking-opponent results are kept separately. Storage rejection leaves the current visit playable and shows an explicit persistence limitation.

This edition initializes SDL video only and deliberately replaces the native sound adapter with a documented silent backend. SDL's dormant audio support can still be present in the selected binary; SDL_mixer and its codec stack are not linked. Audible playback is unavailable and unverified.

The portable recipe, notice/source package, deduplication and muted standalone/local catalog acceptance are recorded separately from the original private candidate evidence. Production verification is reported in the release receipt. Windows extraction/build directories should be short enough for the host's path limits. Other browsers/devices, all inherited weapon/editor/debug modes, competitive full playthroughs, real quota/crash/rapid-close and migration remain unverified. Preserve private failed probes and prior ROM research. Mario Party2/3 and other Claude-owned games are outside this work.
