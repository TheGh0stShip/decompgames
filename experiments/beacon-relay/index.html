Beacon Relay

Guide a service rover across three original courses. Gather a light and reach each beacon.

Loading browser runtime…

Arrows move / aim · Z or Space jump · X dash · P pause. Jump or dash starts a new relay. A dash recharges on landing. Click the game to focus it.

Developer-released Celeste Classic C# game code by Noel Berry, MIT. Independent compatibility host, rover sprites, font, palette, text and course maps. This prototype is intentionally silent. It contains no original game media and is not the commercial Celeste campaign. A checkpoint records the next course after a beacon is reached; it does not save a mid-course position.
