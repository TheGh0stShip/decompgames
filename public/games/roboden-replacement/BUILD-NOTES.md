Eligible scope: an experimental ROM-free, silent geometric edition of the author-released MIT Roboden game, not a retail decompilation, all-CC0 codebase, certified clean-room reconstruction or original-content-equivalent remake.

Actual package includes all557 independently authored asset files with retained MIT bitmap font and dependency notices. It deliberately uses simplified geometric shapes, silent audio and pass-through effects. Source reconstructs current build20 byte-identically with the documented Go1.27.2/module environment. Uninstrumented build19 completed tutorial/results and earned profile restoration using real screenshot-guided input; build20 only changes fallback icon fill and passes normal Blitz command/render/profile reload checks.
