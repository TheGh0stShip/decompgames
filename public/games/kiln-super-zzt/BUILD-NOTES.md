# Kiln / Super ZZT relay edition

Original four-board CC0 puzzle content for a reconstruction-derived native C++ source port/rewrite. The port is not the matching Pascal/DOS binary or CPU emulation, and is not certified clean-room. No original retail world, screen, font, animation, recording, executable, ROM or Turbo Pascal toolchain is included or needed.

Selected native source derives from OpenZoo/openzoo-prototype-cpp 442ff28c423faa947793e8a69a99a0e98f52796d under MIT. Explicit permission-backed Super ZZT reconstruction evidence is asiekierka/reconstruction-of-super-zzt 012df7266760e6d5cc9f49cecc3a3ac093ea26b9. Separate full grants/notices are retained. This edition reuses the previous scoped browser adaptation: external authored bitmap, POSIX file API, Emscripten entry/input/render adaptation and disabled audio device; two sequel defaults select Super ZZT before UI construction and startup world KILN.

45 native source/header files and authored/config.h are the selected compiler closure. The build compiles all 22 supplied .cpp translation units with C++20/O1, SDL2 and pthreads, and preloads only authored ASCII.BMP/KILN.SZT/ABOUT.HLP. Root MIT applies to native source; own build/world generator/host/storage/validator are MIT under AUTHORED-ADAPTER-LICENSE.txt. Font generator and generated content are CC0-1.0. Native embedded messages and procedural tone code retain upstream MIT; runtime libraries retain their separate permissive grants. Consult notices, including yuv2rgb BSD-3-Clause, selected runtime/header notices and emitted-JavaScript MIT notices. No blanket CC0 applies to runtime code.

Rebuild with Python 3 and Emscripten 6.0.10, emsdk commit d6c521a7f05449857c76bd99e396895583cf2083. SDL2 port recipe pins 2.32.10 and verifies its SHA-512 archive. Use the SDK's em++ on PATH, or set EMXX to its em++.py and EM_CONFIG to its .emscripten configuration. No prior object, runtime .wasm/.data, toolchain source or retail input is needed in this archive. The SDK/runtime source stays an external build dependency with retained notices and exact audit inventory hashes.

Run: python authored/generate-font.py; python author-world.py; python build.py. Font generation now uses only the Python standard library and reproduces the supplied bitmap byte-for-byte. Optional KILN_LINK_TRACE=1 emits the actual linker archive/member trace and build/linked.map without changing WASM/data. The build retains 19 known warnings, including legacy warning pragmas, an unused format argument and pthread/memory growth. They are not hidden or waived by the gameplay test.

Serve build/ over HTTP with Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp; it requires WebAssembly threads/cross-origin isolation and should open as a top-level tab. Do not test audibly: this edition creates no audio device. Click canvas, Enter, P and arrows. S writes a native SAV; wait for Checkpoint saved locally. R loads from the start menu; move to resume. Escape/Y returns to menu and P resets the authored world. The host Stop button navigates to the catalog detail route and unloads the game; local standalone servers should serve that route or close the tab.

Native saves are stored separately under decompgames-kiln-super-zzt-saves-v2. Structural admission covers this four-board pack, including stopped script position -1. It is not authentication or a hostile-script sandbox. No transfer/export/import or crash/rapid-close/storage-denial promise. See audit summaries for tested scope and limitations. Original puzzle has no lethal/combat hazards. It is not the original retail campaign or proof of all engine/editor/glyph paths.
